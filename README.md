# 签数 · 标签用量助手

私有代码仓库。当前代码与本机签数的计算、预览、搜索、打印功能一致，未包含公司标签库、个人数据库或文件备份。

## 本机运行

macOS双击 `start.command`。或运行 `python3 launcher.py` 后访问 http://127.0.0.1:8767/ 。如果同一端口已有签数，会复用正在运行的实例。

在浏览器导入整版PDF、PDF兼容AI或尺切工程。输入枚数后自动计算纸张数量，打印时生成对应页数，系统打印窗口使用1份及实际大小100%。

标签数据保存在当前浏览器的IndexedDB中。网页托管和标签库跨设备同步是不同功能；当前版本未连接云端数据库。更换浏览器或地址前使用标签库导出/恢复迁移自己的数据。

## 私用部署

此仓库保持Private，不启用GitHub Pages。普通GitHub Pages可能对互联网公开，即使来源仓库是私有。

需要在线私用时，选择带访问保护的服务器或仅本人可访问的ChatGPT Sites，并为标签文件与数据库接口同时配置认证。不要把公司标签直接放进公开静态目录，也不要把GitHub令牌写进网页。

`dist/samples/index.json` 为不含业务数据的空目录。要部署共享标签库，需在受保护环境中单独导入本机数据，并检查匿名用户不能读取PDF与缩略图。当前本机211款标签未随仓库上传。

## 检查

`node --test tests/*.test.mjs`

测试只使用可丢弃的计算和分类样例，不触发打印机或生产数据库。

第三方浏览器依赖和字体许可位于 `dist/vendor/` 和 `dist/fonts/`。
