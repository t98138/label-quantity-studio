# 签数 · 标签用量助手

导入已经排版好的标签，输入所需枚数，自动计算纸张数量并生成打印页。

- 支持整版 PDF、PDF 兼容 AI 和尺切工程。
- 按产品和包装分类，支持中文、英文关键词搜索。
- 单标签预览与整版预览切换。
- 按每行枚数、每纸行数计算用纸、剩余枚数和多出数量。
- 打印时自动生成对应页数；系统打印窗口选 **1 份、实际大小 100%**。
- 标签库可导出、恢复；每个 PDF 最大 30MB，单次最多生成 500 页。

## 本机运行

macOS 双击 `start.command`，或执行：

```sh
python3 launcher.py
```

访问 http://127.0.0.1:8767/ 。该启动器仅监听本机地址。

也可以用任意静态 Web 服务器托管 `dist/`，无需构建或安装 npm 依赖。

## 数据与隐私

开源仓库只含程序代码和第三方运行依赖，不附带业务标签、客户资料或数据库。
`dist/samples/index.json` 默认为空，用户可自行导入标签。

个人导入的标签保存在当前浏览器的 IndexedDB 中；部署网页不会自动同步这些数据。
换电脑、浏览器或站点地址前，请导出标签库，再在新环境恢复。
服务器可单独托管受保护的共享模板目录，但这不是多人编辑数据库。

公司模板应在 Git 仓库外保存，并对网页、PDF、缩略图和目录清单一起配置访问认证。
不要将业务文件或登录凭据提交到公开仓库。

## Debian / Docker 部署

参见 [部署说明](deploy/README.md)。生产环境通过静态服务器提供文件，
计算、预览与 PDF 处理在客户端浏览器完成。内存和 CPU 消耗主要取决于客户端文件规模。

## 验证

需 Node.js 22 或更新版本：

```sh
npm test
```

测试使用可丢弃的计算和分类样例，不连接打印机或生产数据库。
